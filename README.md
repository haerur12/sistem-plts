# Solar Project Monitoring and Reporting System

A web-based Project Monitoring and Reporting Information System developed for **PT Energy Lima Pilar** to support solar photovoltaic (PLTS) installation project management. The system is designed to centralize project information, simplify field reporting, monitor project progress, manage installation schedules, and track solar component inventory.

## Overview

Managing project data through separate files and communication channels can lead to duplicated records, delayed reporting, and difficulties monitoring project progress. This system aims to address these challenges by providing an integrated web application for project managers, field technicians, administrators, and warehouse staff.

## Key Features

- **User Authentication** — Login and access control for authorized users.
- **Customer Management** — Manage and organize customer information.
- **Project Management** — Create, update, and manage solar installation projects.
- **Project Progress Monitoring** — Track project status and progress updates.
- **Installation Scheduling** — Organize project schedules and installation activities.
- **Field Reporting** — Record field activities and upload photo documentation.
- **Inventory Management** — Manage solar components and stock availability.
- **Dashboard and Reports** — View project information and generate reports for operational monitoring.

## Technology Stack

- **Backend:** Native PHP
- **Database:** MySQL
- **Frontend:** HTML, Tailwind CSS, JavaScript
- **Development Methodology:** Scrum

## User Roles

The system is designed to support the following roles:

- **Administrator:** Manages users and system data.
- **Project Manager:** Monitors projects, schedules, progress, and reports.
- **Field Technician:** Updates project progress and submits field reports.
- **Warehouse Staff:** Manages solar component inventory and stock information.

## Testing

The system can be evaluated using **Black Box Testing** to verify whether each feature produces the expected output for given inputs. **User Acceptance Testing (UAT)** may also be conducted to assess whether the application meets the operational needs of its intended users.

## Project Objectives

- Centralize customer and project information.
- Simplify project progress monitoring and field reporting.
- Support coordination between project managers, technicians, and warehouse staff.
- Provide structured information about solar component availability.
- Support more efficient project administration and operational decision-making.

## Project Status

This project is developed as a web-based information system for monitoring and reporting solar installation projects. Features and implementation details may evolve throughout the development process.
